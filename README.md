# HR Employee Attrition analysis project using Python.
This project analyzes employee attrition using python to identify patterns and understand why employees leave the company.

#TOOLS and LIBRARIES
 -Python
 -Pandas
 -Seaborn
 -Matplotlib
 
#Dataset Features
 -Age
 -Gender
 -Department
 -Salary
 -Years at Company
 -Attrition
 
#Project steps
-Loaded Excel dataset using Python
-Explored data using head() and info()
-Checked attrition distribution using value_counts()
-Performed groupby analysis:
   Department vs Attrition
   Gender vs Attrition
   Salary vs Attrition
-Created viualization using Seaborn countplot

#Visualization
Countplot showing attrition across departments (HR,Sales,IT)

#Key insights 
-Sales department has higher attrition
-Employees with lower salary leave more
-Attrition varies by department
-Retention strategies needed for team

#Conclusion 
This projects demonstrates basic exploratory data analysis (EDA) and visualization to understand employee attrition trends
